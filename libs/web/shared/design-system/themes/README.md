# Vendored themes

`<brand>/DESIGN.md` files are copied unmodified from
[voltagent/awesome-design-md](https://github.com/voltagent/awesome-design-md) (`design-md/<brand>/DESIGN.md`),
which is MIT licensed. Copyright remains with the original authors.

`<brand>/mapping.yaml` is authored here: it maps each token of `src/tokens/contract.ts` to a path in that
brand's DESIGN.md frontmatter, or to a literal when the brand does not define it.
